Project Description:

  Build a Vehicle Parking System web application where end users can register vehicles, book/release parking spots, and export their history, while admins manage lots, users, and dashboards.  
  The backend is Python/Flask with Celery for scheduled jobs and exports. The frontend is a Vue 3 SPA (Vite) that consumes the REST APIs.

How to Run (summary):

  1. Backend
     - python3 -m venv venv && source venv/bin/activate
     - pip install -r requirements.txt
     - flask --app app.py run (or python app.py)
  2. Celery workers (for tasks.py jobs)
     - celery -A celery_app.celery worker --loglevel=info
     - celery -A celery_app.celery beat --loglevel=info
  3. Frontend
     - cd frontend && npm install && npm run dev

Database Schema (SQLite):

  1. Users
     - user_id INTEGER PK AUTOINCREMENT
     - email TEXT UNIQUE NOT NULL
     - password TEXT NOT NULL (bcrypt hash)
     - name TEXT NOT NULL
     - address TEXT NOT NULL
     - pincode TEXT NOT NULL
     - role TEXT DEFAULT 'user'

  2. ParkingLot
     - lot_id INTEGER PK AUTOINCREMENT
     - location_name TEXT NOT NULL
     - address TEXT NOT NULL
     - pincode TEXT NOT NULL
     - price INTEGER NOT NULL (per hour)
     - maxSpots INTEGER NOT NULL

  3. ParkingSpots
     - lot_id INTEGER FK → ParkingLot
     - spot_id INTEGER
     - status TEXT CHECK('O','A') DEFAULT 'A'

  4. Reserve_Parking_Spot
     - spot_id INTEGER FK → ParkingSpots
     - lot_id INTEGER FK → ParkingLot
     - user_id INTEGER FK → Users
     - vehicle_number TEXT NOT NULL
     - parking_timestamp DATETIME NOT NULL
     - leaving_timestamp DATETIME
     - parking_cost REAL

  5. Vehicles
     - user_id INTEGER FK → Users
     - vehicle_number TEXT UNIQUE NOT NULL
     - vehicle_status TEXT NOT NULL ('active','inactive')

API Design (high level):

  • Auth (register/login/logout, session-based)
  • Admin APIs (lots CRUD, spot management, users list, summary metrics)
  • User APIs (dashboard data, book/release spots, vehicle CRUD, export CSV via Celery)
  • All endpoints documented in api.yaml.

Architecture & Features:

  • Flask app configured with blueprints (auth/admin/user) and uses SQLite for persistence.
  • Vue SPA handles all logged-in interactions; it stores session info in browser storage and calls the Flask APIs with credentials.
  • Celery handles asynchronous jobs: daily reminders, monthly summary emails with charts, and parking history export (CSV saved under exports/ and notification via Google Chat).
  • Role-based UI: Admin views for lot management; User views for booking, vehicle management, history, and exports.
  • Charting/analytics implemented on the admin summary page.
